Releases

Release 0.7.0 (0.7.0)

Diese Modul erlaubt die Steuerung von zwei Heizsysteme über ein HVAC Gruppenobjekt. Z.B. kann damit eine Klimaanlage zum Kühlen und Entfeuchten verwendet werden, während zum Heizen die Fußbodenheizung verwendet wird. **Features:** - Zwei Heizsysteme über ein HVAC Gruppenobjekt - Intelligenter Fenster offen Modus - Tagesdurchschnitttemperaturberechnung - Automatische Winter- Sommerbetrieb Umschaltung - Zwei getrennte Sollwerte für Heiz- und Kühlbetrieb - Automatikbetrieb zur Umschaltung vom Klimagerät zur Fußbodenheizung **Ansteuerung der Heizsysteme** - Regelung durch den Heizungsaktor - Regelung durch den Klimaanlage - Regelung durch OpenKNX durch Stellwertvorgabe - Regelung durch OpenKNX durch Sollwertvorgabe (Damit kann z.B. ein KNX Temperatursensor verwendet werden und die Klimaanlage damit zu Steuern - OpenKNX Regelung mit Pulsweitenmodulation, damit könnten Thermoelektrischeventile über einen beliebigen Schaltaktor geregelt werden

*: automatisch ermittelt aus aktuellem Release. Nicht jedes Gerät wird zwingend den vollen Funktionsumfang unterstützen bzw. können Module bestimmte Hardware-Fähigkeiten zur Nutzung erfordern.
