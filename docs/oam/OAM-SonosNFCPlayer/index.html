Release 0.6.0 (0.6.0)

New Features: - Sonos Online Check with Ping - Refactoring of Sonos Benachrichtigungen, diese wurden nun in ein Modul ausgelagert, damit sind mehr verschiedene Benachrichtigungsquelle möglich. Breaking Change: Leider gibt es dadurch ein Breaking Change, wenn bisher mehr als eine Benachrichtigungsquelle konfiguriert war, muss die Konfiguration anpassen, es gibt nun keine Schalt-KO's mehr um jede Benachrichtigung auszulösen. Statt dessen kann man über den neuen KO "Benachrichtigungs Nr starten" die Möglichkeit über einen numerischen Wert direkt eine Benachrichtigungsquelle zu starten. Über das Logikmodul kann aber leicht das alte Verhalten mit einem Schaltkanal nachgebaut werden. Ein Schaltkanal steht außerdem pro Kanal weiterhin zur Verfügung, in der Anwendung stellt man dann die Quelle eine, die damit abgespielt wird.
