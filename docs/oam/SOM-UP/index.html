Release Version 1.2.3 (1.2.3)

Es wurde auf die neust Common 1.5.1 und die neue ESP8266Audio geupdated. Relevante Änderungen aus den Libraries * Datenübertragen per KNX deutlich stabilder * Verbessertes Abspielen von MP3 Außerdem wurden die Hilfe etwas überarbeitet.

Release Version 1.1.0 (1.1)

**Achtung: Aufgrund des neuen KNX-Stack kann es sein, dass die PA neu programmiert werden muss!** Diverse Updates der verwendeten Libraries: * OGM-Common 1.4.0 * OFM-Network 0.5 * OGM-Logkmodul 3.7.0 * OFM-ConfigTransfer 0.4.0 Außerdem wurde der KNXIP-Support integriert, so dass zukünfitge Geräte auch über IP statt TP angebunden werden können.

Release der ersten finalen Version. - Update der UI - Updates des OpenKNX-Framework - Updates aller OpenKNX-Module - Update auf neuen KNX Stack - Updates der sonstigen Libraries
